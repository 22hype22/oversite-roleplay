# CLAUDE.md, Oversite Roleplay bot

Single-file discord.py bot (main.py). Auto-deploys to Railway from main.

This repo is a mirror of github.com/22hype22/oversite-customs kept in
sync by .github/workflows/sync.yml. Do not edit main.py here: change
oversite-customs, then run the sync workflow (or wait for the hourly run).
The only difference is the BOT_BASE default of "roleplay", which sets the
brand, the slash commands kept, and the dashboard blocks loaded.

Message rules: no emoji or symbol glyphs, no em dashes, no parentheses,
no AI voice. Ratings are written out, "4 out of 5".
